# Sloppy Potato Fantasy Football — design directions

The pen.dev comparison board uses the same Week 4 matchup content in every concept so color, typography, density, and personality can be compared directly. Each direction includes a 1440px desktop frame and a compact mobile frame.

## A — Dark Draft

An amber-on-charcoal sports-broadcast treatment. It feels serious, fast, and at home during late-night waiver research. This is the strongest base for dense rankings, draft boards, and an agent research desk.

## B — Clean Command

A light, electric-blue dashboard treatment. It is the clearest and most familiar option for friends who use mainstream fantasy apps, with the best daylight readability and the least visual novelty.

## C — Sloppy Arcade

A tangerine, cream, black, and yellow color-block treatment with the potato mascot mark. It has the most distinctive personality and best expresses the Potato Bowl After Dark inspiration, while keeping data tables readable.

## Selected direction

**Dark Draft** was selected on September 1, 2026. It is the canonical structural and visual system for implementation: charcoal surfaces, amber emphasis, condensed sports typography, crisp data tables, and late-night broadcast atmosphere. The potato identity remains in the original mascot, naming, and restrained microcopy rather than changing the core color system.
